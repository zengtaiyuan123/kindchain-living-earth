## 已修复的问题

| 问题 | 影响 | 处理位置 |
| --- | --- | --- |
| 私有读取接口的账户 scope 校验不统一 | 切换账户后，旧页面部分读取可能展示当前账户的数据；未发现可凭此读取任意第三方账户 | 主站与独立版共用 requestIdentity：凡携带 scope 均核对，过期上下文返回 409 |
| 登录链接在内嵌工作区被改为当前 iframe 打开 | 邮箱页的禁止嵌入策略可能导致登录打不开 | 主站与独立版统一将认证导航设为顶层 |
| API 认证失败返回 HTML | 前端 JSON 解析报错，掩盖实际登录过期或服务故障 | 独立认证网关 API 分支返回 JSON，401/503 与清理 cookie 保留 |
| 登录后每个地形瓦片重复请求远程身份服务 | 手机地图加载增加无必要的网络延迟 | 仅固定公共地形 GET/HEAD 跳过身份查询，仍剥除伪造身份头；私有接口继续校验 |
| 部署检查仅排除一个占位 ID | 缺失或格式错误的数据库 ID 也可能通过 | 校验 UUID 格式、占位值与 D1/R2/ASSETS/IMAGES 绑定 |
| 补丁覆盖共享文件前缺少内容比对 | 给已有改动的副本打补丁时可能覆盖本地更改 | 对共享修复文件校验允许的基线 SHA256，不符则停止 |

## 仍是发布/验收条件

1. 真实认证服务与 SMTP 未接通：本次验证使用模拟认证响应，未发送邮件。
2. 两个真实邮箱的注册、互相来信、账户切换与隔离未验收；自动测试不能替代。
3. 真机 Safari/Chrome、输入法、自动填码、弱网及推送交付未验收；此环境没有可用的受支持浏览器测试路径。
4. 生产邮件发件域名、发送限额、上游防滥用与 Cloudflare 可信 IP 限流必须配置；本补丁不自动创建这些服务。
5. 当前邮箱会话最长一小时，尚无自动续期。退出会清本地凭证，但不承诺已签发 JWT 立即全局失效。
6. 独立域名、云资源和数据库迁移未执行。旧 ChatGPT 用户与新邮箱用户不按邮箱自动合并；生产数据不在补丁里。
7. 支付、提现、大屏履约仍未接通，保持原有禁用/未开放提示。
